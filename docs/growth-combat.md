# 영구 성장과 군집 전투 · 0.14.0

기준은 공개 0.13.0, main `0ab8455312c0633df6f59376d7d4625aebc5a2f9`(PR #7)이다. 작업 시작 시 열린 PR과 이후 main 변경은 없었다. 이번 변경은 판 안의 소모 강화를 도전 밖의 영구 성장으로 교체한다. 기존 도감·설정·기록은 유지하고 프로필에 `shells`와 `growth`를 추가한다. 구 버전은 이 필드를 보존하지 않으므로 MINOR 0.14.0으로 올린다. 별도 저장 버전과 호환 실행 경로는 만들지 않는다.

## 조개와 구매

기존 완성 보상, 콤보 보상, 속도 웨이브 보너스, 웨이브 완료 보상을 그대로 조개로 지급한다. `Simulation.rewardShells`가 방어 모드의 확정 사건을 발행하고 `Profile`이 즉시 저장한다. 볼 중간의 임시 보상은 여전히 볼 완성 전까지 지급하지 않는다. 패배·도전 종료·새로고침 시 이미 얻은 조개를 초기화하지 않는다.

구매는 조건·현재 단계·최신 저장 잔액을 다시 확인하고 조개 차감과 단계 증가를 하나의 localStorage 값으로 기록한다. 저장 성공 후에만 메모리 프로필을 교체한다. 저장이 거부되면 구매하지 않는다. 연속 더블클릭은 400ms 동안 한 구매로 취급하며 최대 단계는 다시 살 수 없다. 브라우저 탭의 저장 이벤트로 잔액·트리를 갱신한다. 서로 다른 브라우저·기기 사이 동기화는 없다.

연습에서는 조개·도감·기록을 저장하지 않는다. 기존 영구 성장은 연습의 조작에도 적용된다. 도전 중 트리는 조회할 수 있지만 구매는 종료 후에만 가능하다. 시작 시 프로필 단계를 복사하여 그 판 전체에 적용한다.

## 전투 조정

- 부화장은 공격하지 않는다. 방어 시작 시 불꽃싹 1명을 즉시 제공한다. 무료 시작 동료는 부화 통계·도감·보상을 만들지 않는다. 직접 부화의 첫 불꽃싹·두 번째 바위갓·이후 셔플백은 유지한다.
- 원거리 4역할 사거리 560, 첫 비행 속도 420, 연쇄 속도 270. 540×470 맵에서 나타난 적을 즉시 표적으로 삼을 수 있다. 일반 적은 y=48, 보스는 y=105에서 화면 안에 나타난다.
- 이동 대형과 공격 사거리를 분리한다. 원거리 표적에 기존 `leash + 90` 제한을 적용하지 않는다. 근접 바위갓은 기존 근접 범위를 유지한다. 후열의 실제 대형 위치가 이동 제한 밖이 되지 않도록 대형 반경을 제한에 포함한다.
- 실제 공격탄·속성 형태·반응은 모두 렌더한다. `projectileBounce` 사건에서 0.22초 방향 궤적·회전 고리, 착탄에서 짧은 압축 반동을 만든다. 얼굴에 실을 붙이는 표현은 없다. 예산 150개는 장식 실 파티클에만 적용한다.

| 무리 | 수 | 군집당 수 | 군집 간격 | HP 배율 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 36 | 6 | 5초 | 0.8 |
| 2 | 60 | 10 | 5초 | 0.9 |
| 3 | 90 | 15 | 4.5초 | 1.0 |
| 4 | 132 | 22 | 5.5초 | 1.15 |
| 5 | 180 + 보스 | 30 | 6초 | 1.35 |

일반 적 총 498명 + 보스 1명. 보스 HP 1050은 유지한다. 최초 초안의 4~6명/짧은 간격은 후반 동시 적이 약 15명으로 적어 위 군집으로 조정했다. 동시 적 cap은 192다. cap에 막히면 생성 수·보스 생성 여부를 올리지 않고 다음 틱에 재시도한다. 투사체 cap 160에서 공격탄을 만들지 못하면 공격 쿨다운을 소비하지 않는다. 물꽃술사는 공격탄을 먼저 확보한 뒤 여유가 있을 때 별도 치유탄을 낸다.

`SpatialGrid`에 살아 있는 ID와 점유 셀 경계를 함께 보관한다. 비행 표적은 ID로 조회하고, 다음 튕김 표적은 반경 후보에서, 충돌은 이동 선분의 swept 후보에서 판정한다. 투사체마다 전체 적 목록을 순회하던 경로를 제거했다. 아군은 유효 표적을 유지하고 새 표적 선택 때 정렬 대신 최근접 한 명을 고른다. 렌더의 반동 대상도 프레임마다 한 번 인덱싱한다. 새 엔진이나 호환 계층은 없다.

## 검증과 전달

명령: `npm run check`, `npm test`, `npm run test:growth`, `npm run test:elements`. 실제 결과와 SHA, 성능 비교, 공개 배포 확인은 이번 PR에 기록한다. 생성된 영상·JSON·임시 내부 경계/벤치마크 코드는 영구 회귀 테스트로 추가하지 않는다.

`test:growth`는 조개 100개를 이미 보유한 기존 사용자 프로필에서 출발한다. 선택/조건/명시적 구매/더블클릭/도전 중 구매 차단/자연 패배/재시작/실제 방어 부화/즉시 새로고침을 검증한다. `test:elements`는 정상 HP·피해·스폰·이동을 사용하되 성공 Good 부화를 5초마다 제공한다. 130~144초는 실제 시간으로 렌더하고 나머지는 60Hz로 빠르게 진행한다. PC는 기본 3회, 390px은 성장 5회 튕김으로 5무리와 보스까지 확인한다. 이는 사람의 무보조 5웨이브 난이도 검증이 아니다.

실기기 모바일, 사람의 청취, 모든 재질/특성 조합과 장기간 성장 경제는 미검증이다. GameKit v0.3.1 고정 dist와 기존 Pages workflow를 그대로 유지한다.
