## 탄의 생명주기와 상태 소유권

`AttackProjectile`은 하나의 ID/위치/궤적/대상/방문 목록/튕김 횟수를 소유한다. `ProjectileTargets`는 현재 위치에서 유효 대상 선택과 선분-원 swept collision을 공유한다. `AbilityPayload`는 피해와 한 번의 반응 변환을 소유한다. `ElementStatus`는 각 적의 공유 노출·화상·감속·빙결 시간을, `Unit`은 HP 변경을 소유한다. `Simulation`이 60Hz로 갱신하며 Renderer/오디오는 확정 사건을 읽는다. VFX 콜백으로 피해를 적용하지 않는다.

- 최초 명중 + 최대 3회 튕김, 근처 140 거리, 같은 탄의 같은 적 재방문 금지.
- 공격탄은 실제로 이동하며 경로의 첫 적에 맞는다. 주변 적 여러 명에게 즉시 피해를 주지 않는다.
- 다음 표적이 없으면 종료. 비행 중 대상이 죽으면 현재 위치에서 유효 대상을 찾고, 없으면 종료한다.
- 기본 탄속 270, 한 비행의 최소 목표 시간 0.16초, 도착 대기 0.075초, 피해는 튕김마다 ×0.8. 탄의 최대 수명은 7초다.
- 속성 노출은 2.4초. 같은 속성의 화상/감속은 갱신하며 중첩해서 더하지 않는다.
- 부화장 바늘도 같은 경로의 중립 공격탄이다. 원래 바늘 피해·발사 간격·강화·여러 초기 표적은 유지한다.
- 치유탄은 같은 이동 생명주기를 쓰되 아군의 현재 부상 대상을 향하며, 적 피해/노출/반응/튕김을 갖지 않는다. 회복은 도착할 때 확정한다.
- 첫 부화 불꽃싹, 두 번째 바위갓, 이후 병종 셔플백과 한 볼의 보너스 병종 복제는 유지한다. 저장 도감의 `0..4` 키도 유지한다.

## 공유 속성 반응

서로 다른 아군 탄이 한 적에 남긴 노출을 공유한다. 양쪽 명중 순서 모두 반응한다. 반응할 때 기존 대응 노출을 소비하고, 탄의 시각/효과를 바꿔 다음 표적으로 운반한다. 탄마다 한 번만 변환하며 추가 탄/재귀 광역 분기는 없다. 이미 변환된 탄은 새로운 속성 노출을 쌓지 않는다.

| 조합 | 운반하는 반응 | 효과 |
| --- | --- | --- |
| 불씨 + 물 | 증기 | 해당 명중 피해 ×1.2 +2 |
| 물 + 냉기 | 빙결 | 0.55초 이동/공격 정지, 이후 1.4초 동안 이동 50% |
| 물 + 번개 | 전도 | 피해 ×1.25, 전달 범위 +40, 탄속 ×1.1 |

준비는 캐릭터 옆의 작은 속성 탄과 몸의 수축으로, 실제 탄은 짧은 궤적과 고유 도형으로, 명중은 국소 반동과 발밑 파열로 표현한다. 노출 상태는 얼굴 아래 발밑의 작은 도형으로 표시한다. 거대한 전격 연결선이나 얼굴 실 장식은 쓰지 않는다. 털실 표면은 기존 곡선 스티치·가장자리·섬유 렌더를 유지한다.

## 검증 범위

`npm run check`: 공식 GameKit 모듈 해시와 제품 ESM 구문.
`npm test`: 정상 입력 → 부화 → 도감 → 일시정지 → 저장/새로고침 → 일반 방어.
`npm run test:elements`: 고정 seed의 실제 웨이브·정상 HP/피해/이동/둥지 사격을 쓰는 혼합 편성 전투. 성공 Good 부화만 5초마다 스크립트로 제공한다. PC/390px을 순차 재생하고 실제 속도 영상·캐릭터 그림·탄 이동·3종 반응 전달·저장 불변을 `artifacts/element-combat/`에 기록한다.

내부 경계 검사는 개발 중 임시로 실행하며 저장소에 영구 단위 검사로 남기지 않는다. 실기기 모바일, 사람의 청취, 전체 5웨이브 밸런스는 이 작업의 검증 범위가 아니다. 화면 PASS는 자동 assertion만으로 선언하지 않고 실제 캡처·녹화의 연속 프레임을 확인한다.
