기준 main: `0ab8455312c0633df6f59376d7d4625aebc5a2f9`.
모든 원거리 기본 공격은 공통 공격탄의 실제 비행을 사용한다. 폐기된 표식 준비/버섯 4타 기폭과 순간 주변 관통 피해는 재도입하지 않는다. 아래 값은 게임별 조정값이다.

| --- | --- | --- |
| 바위갓 | 땅, 근접 전열, 튕김 제외 | 넓고 낮은 돌빛 갓과 두꺼운 발 |
| 불꽃싹 | 불씨, 2초 동안 초당 1.5 화상 | 테라코타 몸과 세 갈래 불꽃 싹 |

| 물꽃술사 | 물/젖음, 별도 치유탄 14 회복 | 청록 물방울 몸과 밝은 물꽃 |

## 탄의 생명주기와 상태 소유권

`AttackProjectile`은 하나의 ID/위치/궤적/대상/방문 목록/튕김 횟수를 소유한다. `ProjectileTargets`는 기존 SpatialGrid의 반경/swept 후보로 다음 표적과 선분-원 충돌을 고르고, 비행 표적은 ID로 조회한다. 투사체마다 전체 적을 조회하지 않는다. `AbilityPayload`는 피해와 한 번의 반응 변환을 소유한다. `ElementStatus`는 각 적의 공유 노출·화상·감속·빙결 시간을, `Unit`은 HP 변경을 소유한다. `Simulation`이 60Hz로 갱신하며 Renderer/오디오는 확정 사건을 읽는다. VFX 콜백으로 피해를 적용하지 않는다.

- 최초 명중 + 기본 최대 3회 튕김(영구 성장 4/5회), 근처 기본 140 거리(성장 160/180), 같은 탄의 같은 적 재방문 금지.
- 공격탄은 실제로 이동하며 경로의 첫 적에 맞는다. 주변 적 여러 명에게 즉시 피해를 주지 않는다.
- 다음 표적이 없으면 종료. 비행 중 대상이 죽으면 현재 위치에서 유효 대상을 찾고, 없으면 종료한다.
- 첫 비행 속도 420, 연쇄 탄속 270, 한 비행의 최소 목표 시간 0.16초, 도착 대기 0.075초, 피해는 튕김마다 ×0.8. 탄의 최대 수명은 7초다.
- 속성 노출은 2.4초. 같은 속성의 화상/감속은 갱신하며 중첩해서 더하지 않는다.
- 부화장은 공격하지 않는다. 시작 불꽃싹이 첫 방어를 맡는다. 타워 공격 경로와 전용 강화는 제거했다.
- 치유탄은 같은 이동 생명주기를 쓰되 아군의 현재 부상 대상을 향하며, 적 피해/노출/반응/튕김을 갖지 않는다. 회복은 도착할 때 확정한다.
- 첫 부화 불꽃싹, 두 번째 바위갓, 이후 병종 셔플백과 한 볼의 보너스 병종 복제는 유지한다. 저장 도감의 `0..4` 키도 유지한다.

## 공유 속성 반응

서로 다른 아군 탄이 한 적에 남긴 노출을 공유한다. 양쪽 명중 순서 모두 반응한다. 반응할 때 기존 대응 노출을 소비하고, 탄의 시각/효과를 바꿔 다음 표적으로 운반한다. 탄마다 한 번만 변환하며 추가 탄/재귀 광역 분기는 없다. 이미 변환된 탄은 새로운 속성 노출을 쌓지 않는다.

| 조합 | 운반하는 반응 | 효과 |
| --- | --- | --- |
| 불씨 + 물 | 증기 | 해당 명중 피해 ×1.2 +2 |
| 물 + 냉기 | 빙결 | 0.55초 이동/공격 정지, 이후 1.4초 동안 이동 50% |
| 물 + 번개 | 전도 | 피해 ×1.25, 전달 범위 +40, 탄속 ×1.1 |

준비는 캐릭터 옆의 작은 속성 탄과 몸의 수축으로, 실제 탄은 짧은 궤적과 고유 도형으로, 명중은 국소 반동과 발밑 파열로 표현한다. 노출 상태는 얼굴 아래 발밑의 작은 도형으로 표시한다. 거대한 전격 연결선이나 얼굴 실 장식은 쓰지 않는다. 털실 표면은 기존 곡선 스티치·가장자리·섬유 렌더를 유지한다.

## 검증 범위

`npm run check`: 공식 GameKit 모듈 해시와 제품 ESM 구문.
`npm test`: 정상 입력 → 연습 부화/저장 차단 → 일시정지 → 새로고침 → 일반 방어. `npm run test:growth`: 영구 구매 → 자연 패배 → 재시작 → 실제 방어 부화 → 즉시 새로고침.
`npm run test:elements`: 고정 seed의 실제 웨이브·정상 HP/피해/이동을 쓰는 혼합 편성 전투. 성공 Good 부화만 5초마다 스크립트로 제공한다. PC/390px을 순차 재생하고 실제 속도 영상·캐릭터 그림·탄 이동·3종 반응 전달·저장 불변을 `artifacts/element-combat/`에 기록한다.

내부 경계 검사는 개발 중 임시로 실행하며 저장소에 영구 단위 검사로 남기지 않는다. 고정 성공 부화 조건의 5웨이브와 보스 완주는 검증한다. 사람의 무보조 난이도, 실기기 모바일, 사람의 청취는 검증하지 않는다. 화면 PASS는 자동 assertion만으로 선언하지 않고 실제 캡처·녹화의 연속 프레임을 확인한다.
